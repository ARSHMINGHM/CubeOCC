# CubeOCC Obsidian Vault

Open this folder as an Obsidian vault and start with `00_HOME.md`.

Most important separation:
- `01_CONFIRMED_REQUIREMENTS.md` = explicitly confirmed project facts.
- `02_OPEN_QUESTIONS_AND_AMBIGUITIES.md` = things still needing a decision.
- `08_ARCHITECTURE_RECOMMENDATIONS.md` = suggestions, not requirements.
- `10_DECISION_LOG.md` = chronological changes.

Mermaid diagrams render directly in Obsidian.
